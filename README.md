# Punctuality Intelligence Dashboard

**Project Overview**
I developed this project during my internship at GEOPIC, ONGC. I created an automated system to track the attendance of 161 employees, moving away from manual Excel tracking to a dynamic Power BI environment.

**The Problem Statement**
Before I built this, the HR team had to manually check Excel sheets to find out who was late or absent. It was impossible to see long-term trends or compare different departments. I wanted to create a solution that gave these answers in just one click.

**Methodology and Data Modeling**
I followed a structured approach to ensure the data was reliable:
1. **Data Connection:** I linked Power BI to the project folders so it updates automatically when new files are added.
2. **Data Cleaning:** I used Power Query to filter out weekends and holidays so the statistics remained accurate.
3. **Data Modeling:** I built a Star Schema by connecting five different tables—Attendance Records, Employee Directory, Holiday List, Absentee List, and a Date Table.

**Key Metrics and Features (KPIs)**
I created custom formulas to track the most important details:
* **Punctuality Rate:** The percentage of staff arriving on time.
* **Average Working Hours:** Monitoring productivity across shifts.
* **Interactive Filters:** I added slicers for Department, Shift, and Date so anyone can explore the data easily.
