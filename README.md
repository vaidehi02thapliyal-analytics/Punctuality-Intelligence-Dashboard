Punctuality Intelligence Dashboard
Project Overview
I developed this project during my internship at GEOPIC, ONGC. The goal was to move away from manual attendance tracking and create an automated system to monitor 161 employees. I turned messy biometric data into a clean, visual dashboard that helps HR see exactly what is happening with punctuality.

The Problem
Before I built this, the HR team had to manually check Excel sheets to find out who was late or absent. It was impossible to see long-term trends or compare different departments. I wanted to create a solution that gave these answers in just one click.

How I Built It (Methodology)
I followed a structured approach to ensure the data was reliable:

Data Connection: I linked Power BI to the project folders so it updates automatically when new files are added.

Data Cleaning: I used Power Query to filter out weekends and holidays so the statistics remained fair and accurate.

Data Modeling: I built a "Star Schema" by connecting five different tables—Attendance Records, Employee Directory, Holiday List, Absentee List, and a Date Table. This ensures the dashboard runs fast.

Key Metrics and Features (KPIs)
I created custom formulas to track the most important details:

Punctuality Rate: The percentage of staff arriving on time.

Average Working Hours: Monitoring productivity across shifts.

Absenteeism Trends: Identifying patterns over the 60-day study period.

Interactive Filters: I added slicers for Department, Shift, and Date so anyone can explore the data easily.
